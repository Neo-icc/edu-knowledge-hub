### 2.1 一处必须纠正的口径错误

本报告第一版把「DOI 覆盖率」当成质量指标，得出「教育学基础 1.2%，是最大短板」的结论。
**这个结论是错的**，而且错得很容易误导人。

该领域 242 条证据里，238 条是「柏拉图《理想国》（约公元前 380 年）」这种**一手经典**。
《理想国》没有 DOI——它比 DOI 这个体系早两千三百年。用一个为期刊论文设计的指标去量它，
量出来的必然是接近零，但这不代表内容不可核验：读者拿着书名就能找到书。

正确的口径是**可定位率** =（DOI + 有明确出处）/ 证据总数。按这个口径：

- 教育学基础 **99.6%**，全站最高之一
- 真正偏低的只有脑科学（91.5%），因为它一度有 94 条只写了「作者（年份）+ 中文描述」，
  既不指向书名也不指向论文——**那才是真正的问题**，已在 3.6 处理

体检脚本 `audit-all.js` 已改为输出四级分布与可定位率，不再单列 DOI 率。

### 3.3 脑科学专项：中文叙述式证据的 DOI 补强（0% → 59.4%）

**问题**：脑科学 234 条证据全部写成「Bliss 与 Lømo（1973）在海马发现长时程增强」这种中文压缩式，
没有英文题名，第一轮的题名相似度匹配一条都用不上，覆盖率停在 0%。

**为什么不能直接套第一轮的规则**：纯作者+年份检索召回极差。`Morris 1986` 返回的是经济学书评，
`Gardner & Steinberg 2005` 返回的是地热发电采气系统——同姓不同人。必须加主题词压制。

**做法（两阶段 + 人工判定）**：

1. **候选生成**：用「条目英文名 + 被引作者」做题名检索，过滤「作者姓氏全命中 + 年份差 ≤1」，
   再按题名与条目主题的词面重合度排序。232 条中 130 条得到唯一候选。
2. **逐条人工核对**：把每条的被引中文描述与候选题名并排打印，**逐条判断是否指同一文献**。
   这一步是不可省的——130 个「自动唯一命中」里，约 20% 是错的（书评、同姓不同人、
   同一作者的相邻年份另一篇）。
3. **题名回补**：对判定为「候选错、但我能确定原始题名」的 28 条，用原始英文题名二次检索，
   要求题名相似度 ≥ 0.85 + 作者命中 + 年份差 ≤2。命中 25 条。
4. **全量复核**：把最终 678 个 DOI 全部拉回 Crossref 对一遍，检查是否存在、类型是否为原文、
   年份是否对得上。查出 4 个问题（3 个书评/摘要型记录 + 1 个摘要替代正文），已修正。

**结果**：0% → **59.4%**（139/234）。剩余 95 条是两种情况：经典专著（无 DOI）、
或者候选与描述对不上且我无法确证原始文献——一律留 `null`。

**同时修正的历史错误**（第一轮英文匹配遗留）：

- `10.2307/3340496` 是《Social Learning Theory》的**书评**（Canadian Journal of Sociology，审稿人 Pierce），
  不是 Bandura 原书 → 从 E053 / E272 / E275 三处移除
- `10.1037/e633912013-635` 是 Eisenberger 2003 的 PsycEXTRA 摘要记录 → 换成正文
  `10.1126/science.1089134`

**保留的两条提示**：E150[1]（Harter 儿童知觉能力量表）、E152[0]（成人依恋访谈）指向的是
PsycTESTS 的**测量工具记录**（type=dataset）。被引的本来就是这两个工具，指向工具记录是准确的，
但读者点进去会看到量表信息而非论文——已在报告中标注，未改。

### 3.6 脑科学第二轮：题名回补（59.4% → 85.5%）

第一轮之后脑科学还剩 94 条「仅作者+年份」。这批不该停在那里——它们不是没有出处，
是**当初写证据时只写了中文描述、没写作品名**。三种处理：

1. **题名二次核验（52 条）**：对这些能确定原始文献的条目，直接给出英文题名检索
   （相似度 ≥0.85 + 作者命中 + 年份差 ≤2）。这类匹配准确率很高，抽样相似度多为 1.00。
   例：Hubel & Wiesel 1970《The period of susceptibility…》、Owen 2010《Putting brain training to the test》、
   Miyake 2000、Diamond 2007《Preschool program improves cognitive control》。
2. **同一文献复用（9 条）**：有些证据引用的是**已被其他条目核验过**的同一篇文献
   （如 Miyake 2000 在 E200 已核验、Owen 2010 在 E206 已核验），直接复用已验证的 DOI。
   重复检索反而会引入新的不确定性。
3. **给书名补书名号（12 条）**：剩下的是专著，「LeDoux（1996）情绪脑」这种写法等于没写作品名，
   补成「LeDoux《情绪脑》（1996）」读者立刻能定位。涉及 LeDoux《情绪脑》、Damasio《笛卡尔的错误》、
   Dehaene《阅读脑》《数字感》、Barrett《情绪如何被制造》、Patel《音乐、语言与脑》、
   Bruer《前三年的迷思》、OECD《理解脑》、Ebbinghaus《论记忆》、Wernicke《失语症的症状复合体》。

**结果**：脑科学 DOI 200/234（85.5%），可定位率 91.5%；全站可定位率 97.8%。
剩余 28 条（脑科学 20 条）是「论文但检索不到」或「原始文献本身无编号」，
保持「仅作者+年份」，不硬凑。

## 四、遗留问题（需要人工接力）

### 4.1 教育学基础不需要补 DOI（结论已修正）

第一版报告把它列为「最大短板」，是拿错了尺子（见 2.1）。它的可定位率是 **99.6%**，
引用的是《理想国》《大教学论》这类一手经典，本来就不该有 DOI。

**仍然值得做、但不是 DOI 的事**：给这批经典补「版本信息」——原著年份、通行中译本、
译者、出版社。它比 DOI 对中文读者更有用（读者真正要的是「买哪一本」）。但这件事没有可靠的
公开 API 可核验译者与版次，只能人工核对，属于后续可选项。

### 4.2 全站剩余 28 条「仅作者+年份」

- **无编号的原始文献**：Broca（1861）失语症病例报告、Huttenlocher（1979）突触密度、
  Ebbinghaus 1885 等，检索回来的都是同姓他人的论文或二次文献。
- **检索不到正文的**：如 Rasch 与 Born（2013）《About sleep's role in memory》，
  题名与作者都对得上，但 Crossref 关键字匹配失败（短题名 + 姓氏常见）。

这类保持现状，不猜测、不补造。

### 4.3 两条指向「测量工具记录」的提示

E150[1]（Harter 儿童知觉能力量表）、E152[0]（成人依恋访谈）的 DOI 指向 PsycTESTS
的工具记录（type=dataset），不是论文正文。被引的本来就是这两个工具，指向工具记录是准确的，
但读者点进去看到的是量表信息——保留，已在 3.3 标注。

### 4.4 未命中的 213 条已全部列在报告里

`reports/doi-backfill.json` 的 `miss` 部分包含每条证据的原文与抽取到的题名，可直接作为人工核验的工作清单。

### 4.5 那个一直红的断言：已查明并修好（真 bug，不是误报）

`hub-check.js` 连续多轮报告「折叠态展开按钮尺寸一致：家长端 0×0 vs 研究端 94.6×33.1」。
我一开始把它归类为「与内容无关的布局老问题」压后处理，**这个判断是错的**——它是真 bug，
而且是家长老师入口的**死路**：

- 折叠按钮 `« 收起` 在侧栏头部，折叠后侧栏隐藏；
- 「展开侧栏」按钮 `.fold-float` 住在**顶栏里**；
- 而 `body.embed .topbar { display: none }` —— 嵌入门户 iframe 时整条顶栏被隐藏，
  按钮跟着一起消失。

结果是：用户在 Hub 里进入「家长或老师」，点一下收起，侧栏没了，**页面上再没有任何可点的
展开入口，只能刷新页面**。这条路径正是绝大多数用户的实际路径（门户默认用 iframe 承载）。

**根因是两条同权重 CSS 规则的优先级冲突**：
`body.nav-fold .topbar { display:flex }`（@media 内，折叠态要恢复顶栏）
与 `body.embed .topbar { display:none }`（全局）
特异性同为 (0,2,1)，后者写在后面，赢了。

**修法**：在「嵌入 + 折叠」状态下恢复一条极简顶栏，只留展开按钮，
面包屑与分享/主题仍交给 Hub，不重复：

```css
body.embed.nav-fold .topbar { display: flex; }
body.embed.nav-fold .topbar .crumb,
body.embed.nav-fold .topbar .topbar-actions { display: none; }
```

**结果**：验收 **55/55 全绿**（此前长期 54/55），展开按钮两端均为 94.6×33.1。
